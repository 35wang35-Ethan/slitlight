# 隙光一頁式品牌網站

Bootstrap 5 響應式前台與輕量內容管理後台。

## 本機預覽

```powershell
python -m http.server 8080
```

- 前台：`http://localhost:8080/`
- 後台：`http://localhost:8080/admin.html`
- 測試帳號：`admin`
- 測試密碼：`seam2026`

目前後台使用瀏覽器 LocalStorage 儲存，適合提案／原型展示；正式多人維護上線前，應接入伺服器端驗證與資料庫。
